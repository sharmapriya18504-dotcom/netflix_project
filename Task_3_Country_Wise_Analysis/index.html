Netflix Country-Wise Content Analysis

A geographical evaluation of Netflix catalogue content availability across different countries. Features multi-country explosion, top content contributor rankings, and country-level Movie vs TV Show format breakdowns.

🌍 View Top 10 Countries 📥 Download Country CSVs

Project Overview

Analytical methodology, co-production explosion, and country identification.

🎯 Core Objective

Analyze Netflix catalogue content availability by country. Properly split multi-country co-productions (e.g. "United States, India") using Pandas explode() so every participating country is accurately accounted for.

🛡️ Data Integrity Ethics

We do not claim a country "produced" Netflix content; rather, this indicates Netflix catalogue content associated with that country. 287 titles lacking country information ("Not Given") were excluded from country aggregations.

⚙️ Tech Stack

Implemented in beginner-friendly Python using explode(), value_counts(), and groupby(), visualised with Matplotlib and Chart.js.
