Internship Viva & Evaluation Guide

Key interview questions and clear student-friendly answers for project evaluators.

Q1: Why did df.isnull().sum() show 0 missing values initially when director and country have missing data?
Because the raw dataset uses the text string "Not Given" instead of standard Python NaN or empty cells. Standard Pandas functions treat "Not Given" as a valid text value. We identified this by checking value frequencies and converted "Not Given" into np.nan.
Q2: Why did you NOT delete rows with missing director or country information?
Deleting rows with missing directors would eliminate 2,588 titles (29.44% of the entire library!). Missing a director does not invalidate the title, release year, genre, or duration of a movie or TV show. Dropping them would introduce massive selection bias into future analysis.
Q3: Were there duplicate records in the dataset, and how did you verify?
We verified duplicates using two methods: df.duplicated().sum() for full-row duplicates (result: 0) and df['show_id'].duplicated().sum() for primary key uniqueness (result: 0). Every single row in the dataset represents a distinct content title.
Q4: Why was date_added converted to datetime format?
In the raw CSV, dates were stored as strings like "9/25/2021". Converting them using pd.to_datetime(df['date_added']) enables chronological sorting, year-over-year additions analysis, and filtering by month and day of week.
Q5: What are the main deliverables produced by your Python cleaning script?
The script generates three production deliverables inside the output/ folder: cleaned_netflix_dataset.csv, missing_values_report.csv, and cleaning_summary.txt, plus structured JSON reports for this web dashboard.
