🎓 Internship Viva & Evaluation Guide

Core project methodology, data engineering decisions, and top evaluation questions with model answers.

Q1: Why did you use explode() on Country and Genre columns?
Answer: Titles in Netflix are often co-produced by multiple countries (e.g., "United States, India") or belong to multiple genres (e.g., "Comedies, Dramas"). Splitting by comma and using .explode() counts each individual country and genre participation accurately instead of treating combinations as distinct single entries.
Q2: Why did you convert 'Not Given' placeholders to NaN instead of dropping rows?
Answer: 2,588 titles (nearly 30% of the dataset) did not list a director. If we ran dropna(), we would delete nearly one-third of our valuable data! Replacing 'Not Given' with np.nan allows Pandas to recognize missing data while preserving content type, year, genre, and rating for complete analysis.
Q3: Why did you preserve titles with duplicate names and types?
Answer: While 4 pairs of titles share identical names and types (e.g., "15-Aug", "22-Jul"), each has a distinct show_id and represents a separate catalog entry. Exact full-row duplicates across all columns were 0. We avoid dropping valid records to maintain 100% data fidelity (8,790 titles).
Q4: Why build an HTML/CSS/JS frontend alongside Python analysis?
Answer: Python handles rigorous data cleaning and statistical exports, while an HTML5/CSS3/JavaScript web interface provides an ultra-fast, zero-latency user experience with interactive poster art, instant filtering, and free deployment on GitHub Pages.
